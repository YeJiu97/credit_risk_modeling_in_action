# 风控建模实战

关于风控建模实战的书籍。

# 仓库结构

仓库主体结构如下所示：

~~~text
credit-risk-modeling/
│
├── env/ # 环境配置
│ ├── requirements.txt
│ └── README.md
│
├── data/ # 示例数据（合成/公开小样本）
│ ├── sample/ # 书中示例用的小型数据集
│ └── README.md # 说明数据来源与生成方式
│
├── notebooks/ # 按章节组织的分析笔记本
│
├── src/ # 可复用的建模函数与工具
│
└── reports/ # 图表与结果输出
~~~
